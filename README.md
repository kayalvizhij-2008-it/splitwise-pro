🌟 Project Overview

SplitWise Pro is a premium expense management and smart bill-splitting application built using pure HTML, CSS, and JavaScript.

The application helps friend groups, students, roommates, and teams manage shared expenses efficiently with intelligent settlement optimization and a luxury modern UI.
