# 🌟 Overview

**SplitWise Pro** is a modern luxury-style expense splitter and settlement calculator designed for students, roommates, teams, and friend groups.

The application intelligently manages shared expenses, minimizes unnecessary transactions using a smart settlement algorithm, and visualizes spending patterns with interactive charts.

Unlike basic calculator projects, this application focuses on:

✨ Real-world usability  
🧠 Smart business logic  
📊 Interactive visual analytics  
📄 Professional PDF export  
💎 Premium UI/UX design  
📱 Fully responsive experience  

---

# ✨ Key Features

## 💳 Smart Expense Management

✅ Add expenses with:
- Description
- Amount
- Category
- Date
- Notes
- Payer details

✅ Dynamic participant management  
✅ Real-time calculations  
✅ Automatic updates  

---

## ⚖ Intelligent Settlement Algorithm

The application automatically:

- Calculates net balances
- Optimizes settlements
- Reduces unnecessary transactions
- Shows exactly who owes whom

### Example

Instead of multiple confusing payments:

```text
A → B ₹200
A → C ₹300
B → C ₹100
```

SplitWise Pro intelligently minimizes transactions for cleaner settlements.
